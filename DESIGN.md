# CVE Atlas design direction

## Visual world

CVE Atlas is a calm, luminous research desk for public vulnerability records. Its visual language takes cues from the spacious, pale blue and violet atmosphere of [Love Unseen Beneath the Clear Night Sky](https://sh-anime.shochiku.co.jp/kakekoi/en/) while using original CSS linework and a restrained editorial layout. It does not reuse the anime's artwork, marks, or copy.

## Durable decisions

- Use a porcelain and ice-blue canvas with deep blue ink, periwinkle accents, soft cyan traces, and occasional rose details.
- Pair a literary serif for report titles with a clear sans-serif for reading and monospace only for identifiers and source metadata.
- Give the search area a quiet celestial glow and fine constellation-like linework. Keep report data on a clean paper surface with fine rules.
- Use an editorial two-column report at wide sizes, collapsing the source rail below the record on narrow screens. Recent lookups become horizontally browsable on phones.
- Preserve clear source provenance. Keep the discovery domain visibly unknown unless an authoritative source states it; reference hosts are labeled separately.
- Keep focus rings, selection, links, and interactive states legible against the pale palette. Honor reduced-motion preferences.

## Avoid

- Reusing reference-site artwork, logos, or wording.
- Dark terminal styling, neon hacker clichés, generic dashboard cards, or ornamental effects that compete with the CVE description.
- Treating affected-product vendor domains or reference hosts as proof of where a vulnerability was found or attempted.
